## Потрібно зробити після хостингу

### 1. SSL сертифікат (HTTPS)

Більшість хостингів надають **безкоштовний SSL** (Let's Encrypt).

Як увімкнути:
1. Зайти в панель управління хостингом
2. Знайти розділ "SSL" або "Безпека"
3. Увімкнути "Let's Encrypt" для evakvin.com.ua
4. Перевірити: сайт має відкриватися через https://evakvin.com.ua

---

### 2. Google Search Console

**Крок 1:** Перейти на https://search.google.com/search-console

**Крок 2:** Додати ресурс
- Натиснути "Додати ресурс"
- Вибрати "Префікс URL-адреси"
- Ввести: `https://evakvin.com.ua`

**Крок 3:** Підтвердити власність (HTML-тег)
1. Google покаже код:
   ```html
   <meta name="google-site-verification" content="ваш_код_тут">
   ```
2. Відкрити `index.html`
3. Знайти рядок:
   ```html
   <!-- <meta name="google-site-verification" content="XXXX"> -->
   ```
4. Замінити на код від Google (без коментарів `<!-- -->`):
   ```html
   <meta name="google-site-verification" content="ваш_код_тут">
   ```
5. Завантажити оновлений файл на хостинг
6. Натиснути "Підтвердити" в Google Search Console

**Крок 4:** Надіслати Sitemap
- Меню зліва → "Файли Sitemap"
- Ввести: `sitemap.xml`
- Натиснути "Надіслати"

**Крок 5:** Запросити індексацію
- Меню зліва → "Перевірка URL"
- Ввести: `https://evakvin.com.ua/`
- Натиснути "Запросити індексацію"

---

| Телефон | +380977593507 |
| Сайт | https://evakvin.com.ua |
| Години роботи | Цілодобово (24/7) |

- Підтвердження по телефону (якщо доступно)
